---

## 📋 Зміст

- Я давно писав код для рішення практичних задач, реалізацію замовних фіч. Я хочу поновити базу знать, пропрацювати прогалини в програмувані на Javascript. Я розумію, що зараз код пишется за допомогою Ші. Я його використовував, але він писав коз з критичними помилками, а мої застарілі знання, забуті знання не дали змогу виправити помилки.
- Я використовую VSC, Nodejs, npm, GULP, HTML, SCSS, Vanila Javascript
- Вимоги до середовища: інстальновані VSC, Nodejs, мій проект
